# 前4条摘要补原文：50题对照

2026-10-30完成。沿用上一轮冻结的 `conv-30` 数据库、50道固定问题与旧答案，只新增一组补原文动态回答。模型仍为 `gpt-6.1-sol`、Responses API、reasoning low。未重新建库，未修改正式检索配置。

## 规则

保留原来检索到的最多15条摘要，按其中前4条摘要的顺序补原文。每条摘要最多选最近4条原文候选，按创建时间倒序、同时间原文ID升序；全局按原文ID去重，重复不占额度，累计最多8条不同原文。前两条摘要不足8条时继续第三、第四条，不读取第五条摘要的关联原文。

补入的原文包含带姓名的完整片段，两个字段均为人类发言；不额外加入此前六条历史或阶段摘要。与旧组共用18,000字符、估算6,000 token总证据预算及每条5,000字符上限。15条摘要与最多8条原文共同受总长度限制。此次实际平均补入4.2条，范围2～7条，未发生截断。不同原文记录之间可能有一条边界发言重叠，原文ID去重不等于逐句去重。

## 结果

| 指标 | 原摘要动态组 | 补原文动态组 | 普通Top3 | 普通Top6 |

| 官方F1，37题 | 49.52% | 46.37% | 38.24% | 43.97% |
| 补充语义判分，37题 | 22/37 | 25/37 | 19/37 | 25/37 |
| 官方第五类弃答规则，13题 | 69.23% | 69.23% | 84.62% | 84.62% |
| 多跳题F1，11题 | 30.10% | 20.97% | 27.72% | 31.47% |
| 时间题F1，13题 | 80.27% | 78.22% | 44.69% | 57.73% |
| 单事实题F1，13题 | 35.18% | 36.00% | 40.69% | 40.78% |

官方F1下降约3.15个百分点；其中一题的回答从 `Yes,` 改成 `Yes—`，官方清理只处理半角标点，导致该题从1分降至0分，贡献约2.70个百分点的总均分下降。两条回答均通过语义判分。此处仅解释差异，没有修改官方函数、回答或主分数。其他措辞变化和真实漏项也保留在逐题报告中。F1不是准确率。

补充模型判分中3题由WRONG转为CORRECT，分别补齐了具体地板名称、开业祝福中的共同回忆、计划中的在线平台，没有出现由CORRECT转为WRONG的题目。补原文能够恢复部分同源细节，但并未解决其余多跳漏项、回答漏项或错误前提问题。本轮按官方F1没有获得提升，按补充语义判分有小幅收益，不能称为全面改善。

## 验证与限制

- 原报告和数据库以只读方式复用，前后SHA256一致；三组旧控制答案保持不变。全部50条新增回答和17次新增判分均有已知usage且无接口错误。
- 逐题确认旧摘要保持原样、原文ID不重复、最多8条原文且总长度不超限。去重、顺序、最近4条、前4条种子及长度预算的2项自动测试通过；相关范围TypeScript检查和diff检查通过。
- 这是同一开发样本上的后续对照，包含上一轮保留的5条partial建库记录，不是未见验证集或全部LoCoMo。旧答案沿用、每题只生成一次新答案，没有通过重复调用估计模型波动。
- 只实现了独立评测助手和评测脚本，没有把补原文方案接入正式聊天检索。原数据有369条发言、19次完整会话；原始记忆和分块与上一轮相同。

复现入口为 `scripts/evaluate-locomo-source-supplement.ts`，先设 `LOCOMO_PREPARE_ONLY=true` 可只准备并检查证据，不发送模型请求。脚本固定源报告与输出目录，续跑严格校验模型、原报告、数据库和代码哈希；存在未解决请求时拒绝静默重试。

本地产物位于 `artifacts/locomo-top4-sources8-conv30-50-20261030/`：`comparison.md` 为逐题前后对照，`summary.json`、`scores.json`、`report.json` 和 `semantic-judge/report.json` 保存统计、证据、回答及usage。文档不复制原始人物问答、密钥或数据库。
