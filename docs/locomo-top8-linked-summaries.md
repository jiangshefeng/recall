# Top8 同源摘要扩展：50题对照与离线检查

2026-10-30。实现位于 `scripts/locomo-linked-summaries.ts`，已完成独立离线诊断与50题对照，未接入正式检索。

## 规则

保留原检索的最多15条摘要，取其前8条作为种子，遍历这些种子的全部原文ID，再反查同一scope、同一向量空间内关联任一原文ID的热区摘要。仅使用原文ID，不读取或发送原文正文，不包含冷区旧版本、阶段摘要。

新增候选按摘要ID全局去重，排除原15条中已经存在的摘要；按照与当前问题的向量余弦相似度降序、同分ID升序补入。不对同源候选重新施加0.45阈值，不设置额外的原文候选数量上限，只扩展一次，新摘要不继续触发关联查询。

保留总18,000字符、估算6,000 token、每条5,000字符的原证据预算。条数上限允许容纳原证据与新增候选，但实际是否纳入由共享长度预算决定；预算不足时可能跳过或标记截断。所有摘要成为候选，不代表全部一定发送给模型，也不等于全部与问题有关。
